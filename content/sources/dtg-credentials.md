# Source: dtg-credentials

**Repo**: [OpenVTC/dtg-credentials](https://github.com/OpenVTC/dtg-credentials)
**Type**: Primary
**Language**: Rust
**Latest version**: v0.1.2

## Summary

Rust library implementing DTG credential types (spec v0.3) from the Trust over IP Foundation. Defines Personhood, Relationship, Endorsement, Witness, Membership, Invitation, and Persona credentials plus Relationship Cards. Compact codebase — two source files and an example.
